# Coffee Billing System

A simple Python-based coffee shop billing system that allows users to select coffee items, enter quantities, calculate the total amount, and generate a bill.

## Features

* Display available coffee items and prices
* Select items from the menu
* Calculate the total bill
* Display the final amount

## Technologies Used

* Python
